# Kitfly v0.2.5

**Release date:** 2026-06-22

## Overview

A maintenance release focused on CI/release hardening and a dependency refresh.
There are no user-facing feature changes and no breaking changes.

## Fixed

- **npm publish robustness.** The publish workflow now generates the embedded CLI
  docs (`src/generated/embedded-docs.ts`) before packing. That file backs
  `kitfly docs`, is gitignored, and is **not** produced by `bun run build` — so
  an automated publish from a clean checkout could have shipped a package whose
  `kitfly docs` command fails to load. The publish path now generates it
  explicitly, alongside the release and Windows ARM64 builds.

## Changed

- **GitHub Actions on Node 24.** Migrated `actions/checkout` v4 → v5 and
  `actions/setup-node` v4 → v6 (npm publish runs on Node 24). `oven-sh/setup-bun`
  already targets Node 24. This clears the upstream Node 20 runtime deprecation.
- **Single source of truth for embedded assets.** The Bun-setup + install + embed
  step is consolidated into a shared `./.github/actions/build-prep` composite
  action used by the release, Windows ARM64, and npm-publish workflows (it was
  previously inlined separately in each). CI continues to get the generated asset
  through the Makefile dependency graph.
- **Dependency refresh (patch + minor):** `@3leaps/sysprims` 0.1.15,
  `@fulmenhq/tsfulmen` 0.2.10, `@biomejs/biome` 2.5.0, `vitest` and
  `@vitest/coverage-v8` 4.1.9, `@types/bun` 1.3.14, `prettier` 3.8.4. The
  `marked` 18 and `typescript` 6 majors are deferred to dedicated upgrades.

## Breaking changes

None.

## Notes for upgraders

Nothing to do — drop-in patch. Binaries, the npm package, and the Homebrew
formula are unchanged in behavior.
